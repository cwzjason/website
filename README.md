# 埠勤商贸 (buqin.com.cn)

湖北埠勤商贸有限公司企业网站及业务管理系统。

## 项目结构

- buyuan-company-website/ - 主站 (Node.js + MariaDB)
- schedule-server/ - 日程管理 + AI智能解析
- order-extractor/ - AI订单提取 (Python + 混元HY3)
- ai-assistant/ - 埠勤AI助手 (Python + DeepSeek)
- nginx/ - Nginx生产配置

## 部署

每个子项目均有 .env.example 文件说明配置。
