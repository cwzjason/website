说明：批量图片导入只会为已存在的SKU绑定图片，不会创建新商品。每个SKU需填写单品编码（在商品录入最后一步）。
🏞 步骤2：图片准备与命名规则
重要：图片文件名必须严格遵循以下命名规则，系统才能自动匹配SKU。

命名规则

{SKU}01{XX}.扩展名 → 主图 示例：1520559990101.jpg （SKU=152055999，主图第1张） {SKU}02{XX}.扩展名 → 详情图 示例：1520559990201.jpg （SKU=152055999，详情图第1张） {SKU}03{XX}.扩展名 → 备案截图 示例：1520559990301.jpg （SKU=152055999，备案截图第1张）

• {单品编码} = 商品的唯一编码（数字或字母均可）

• 01 = 主图 / 02 = 详情图 / 03 = 备案截图

• {XX} = 两位数字序号，从01开始递增（01, 02, 03...）

• 支持的图片格式：jpg / jpeg / png / webp / gif

• 一般品类只需主图+详情图，部分品类需要备案截图
